# Найденные критичные ошибки и противоречия

## 1. `GithubPDF.jsx` — два отсутствующих стиля (сломанный PDF-экспорт)

**Файл:** `src/components/export/templates/GithubPDF.jsx`

**Баг A: `styles.contactLine` не определён** (строки 181, 184)
- Email и телефон в шапке PDF рендерятся с `style={styles.contactLine}`, но этого ключа нет в `StyleSheet.create({...})`.
- React-PDF проигнорирует несуществующий стиль — email/phone будут без отступов и без `marginBottom`.

**Баг B: `styles.section` не определён** (строки 191, 210, 235, 261)
- Все четыре секции (skills, repositories, work.log, education.md) ссылаются на `styles.section`, но его нет в StyleSheet.
- Без `marginBottom` секции слипнутся друг с другом без вертикальных отступов.

**Минимальное исправление:** добавить в `StyleSheet.create({...})` два определения:
```js
section: {
  marginBottom: 15,
},
contactLine: {
  fontSize: 9,
  color: '#8b949e',
  marginBottom: 3,
},
```

## 2. `ResumeEditor.jsx:187-217` — двойное присваивание `pendingFocusRef`

**Файл:** `src/components/ResumeBuilder/ResumeEditor.jsx`

В `handleGoToFromRecommendations` переменная `finalTarget` вычисляется на строке 196:
```js
const finalTarget = targetId || fallbackByTab[tabIndex];
```

Затем `pendingFocusRef.current` присваивается дважды:
- строка 212: `pendingFocusRef.current = { tab: tabIndex, target: finalTarget };`
- строка 215: `pendingFocusRef.current = { tab: tabIndex, target: targetId || fallbackByTab[tabIndex] };`

Это **одно и то же значение** (оба `targetId || fallbackByTab[tabIndex]`), поэтому функционально баг не проявляется. Но второе присваивание — мёртвый код, который перезатирает первое. В текущем виде работает, но если кто-то изменит логику `finalTarget`, вторая строка это сломает.

**Минимальное исправление:** удалить строки 215-216.

## 3. `index.jsx` vs `ThemeModeContext.jsx` — двойной ThemeProvider и CssBaseline

**Файлы:** `src/index.jsx` (строки 17-20) и `src/context/ThemeModeContext.jsx` (строки 73-79)

`index.jsx` оборачивает `<App>` в `<ThemeProvider theme={theme}>` + `<CssBaseline />` со статичной светлой темой.

`App.jsx` оборачивает содержимое в `<ThemeModeProvider>`, который **внутри себя** создаёт ещё один `<ThemeProvider>` + `<CssBaseline>`.

Результат: внешний ThemeProvider из `index.jsx` полностью перекрыт внутренним. `CssBaseline` выполняется дважды (без видимых последствий, но это мёртвый код).

**Минимальное исправление:** убрать `ThemeProvider`, `CssBaseline` и `createTheme` из `index.jsx`. Оставить только:
```jsx
ReactDOM.createRoot(document.getElementById("root")).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

## 4. `DEFAULT_RESUME_DATA` определён дважды

**Файлы:** `src/api/resumeService.js:3-10` и `src/components/ResumeBuilder/ResumeEditor.jsx:34-41`

Оба определения идентичны. Если одно будет изменено, а другое нет — данные начнут расходиться. Не баг сейчас, но потенциальная ловушка.
